Dynamic Text Reveal Animation (MATRIX STYLE)

This project creates a fast random-letter flicker effect that slowly transforms into a final word/heading, revealed one character at a time.
The effect is fully built using HTML, CSS, and JavaScript — no external libraries.

---------What It Does----------

Random characters flash rapidly on the screen

Letters stabilize and form the final text smoothly

Reveal happens from left → right

Lightweight and works on all browsers

-------Built With---------

HTML — page structure

CSS — styling and layout

JavaScript — text animation logic
